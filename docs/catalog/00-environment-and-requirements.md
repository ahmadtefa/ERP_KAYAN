# المتطلبات والبيئة وعوائق الإنتاج

## 1. بيئة الإعداد الحالية (2026-10-28) — نتائج فعلية موثقة
| الأداة | الحالة | الأثر |
|---|---|---|
| Flutter / Dart | غير مثبتة، ومضيف التنزيل storage.googleapis.com محجوب | لا تشغيل للواجهة، لا لقطات، لا `flutter analyze` |
| Chromium / Chrome | غير مثبت | لا توليد PDF فعلي ولا لقطات ويب |
| pandoc / LibreOffice / wkhtmltopdf / WeasyPrint | غير مثبتة | لا تحويل إلى PDF/DOCX |
| python3 | موجود (3.x) بلا python-docx/reportlab/weasyprint | سكربت التوليد يعمل بالمكتبة القياسية فقط |
| الخطوط العربية | لا يوجد خط عربي مخصص (DejaVu فقط) | يلزم خط Cairo/Tajawal/Amiri قبل إنتاج PDF |
| PostgreSQL 18.4 | يعمل فعليًا على المنفذ 5433 (embedded) | التكامل الخلفي ممكن ومُثبت |
| Node 22 + npm | متاحان، والاعتمادات مثبتة | البناء والاختبارات الخلفية تعمل |

## 2. المتطلبات اللازمة لإنتاج الكتالوج النهائي
### 2.1 لقطات الشاشة
- بيئة Windows 10/11 عليها Flutter SDK مستقر (نفس نسخة `pubspec.yaml`).
- نسخة مرجعية مبنية: `flutter build windows` (أو تشغيل سطح المكتب) متصلة بخادم
  اختبار عليه بذرة البيانات التجريبية (`npm run seed`).
- بيانات تجريبية آمنة: شركة "Kayan Company"، عملاء/موردون وهميون، أصناف لبن/كابل
  بوحدات متعددة، بلا أسماء حقيقية أو أسرار أو كلمات مرور في الصور.
- أداة التقاط: لقطة نافذة كاملة PNG بخلفية موحدة، اسم ملف حسب `02-screenshot-shotlist.csv`.

### 2.2 إنتاج PDF/DOCX
- خيار A (موصى به): pandoc ≥ 3 + XeLaTeX (xelatex) + خط عربي (Cairo أو Tajawal)
  لتحويل Markdown → PDF مع RTL صحيح.
- خيار B: WeasyPrint + HTML RTL (السكربت يُخرج HTML الجاهز).
- خيار C: LibreOffice لتحويل DOCX وسيط إلى PDF.
- لـ DOCX: pandoc (`pandoc content.md -o catalog.docx`) أو python-docx.

### 2.3 متطلبات المحتوى
- كل لقطة تُحفظ نسخة أصلية غير معدلة في `screenshots/raw/`.
- النسخ المشروحة (أرقام/أسهم) في `screenshots/annotated/` فقط.
- تُربط كل شاشة بفهرس الوظائف والاختبارات في `01-screen-index.csv`.

## 3. ما يمكن إنتاجه الآن فعليًا
- HTML خادم حقيقي لملصقات الباركود (مُثبت: استجابة 200، عربي RTL، سعر بيع
  مستقل، بلا تكلفة) — يصلح كدليل وظيفي وليس بديلا عن لقطات الواجهة.
- كل المحتوى النصي العربي والفهرس وخطة الالتقاط وسكربت إعادة التوليد.
