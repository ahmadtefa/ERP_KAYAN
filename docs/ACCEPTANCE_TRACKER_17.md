## نتائج التحقق المسجلة

- `cd backend && npm run build` — نجح.
- `cd backend && npx eslint src/modules/master-data-backup/*.ts src/modules/notifications/notifications.service.ts src/modules/inventory/stock-transfers.service.ts src/app.module.ts` — نجح. لم تُدرج بعض ملفات الاختبار في ESLint المستهدف لوجود مخالفات `no-explicit-any` سابقة في fixture الاختبارات.
- اختبارات backend المستهدفة: **12 suite / 155 test ناجحًا**. وبعد استكمال معالجة التنبيهات شُغّلت مجددًا suites النسخ الوحدوية والتنبيهات والتحويلات: **3 suites / 64 test ناجحًا**.
- `node scripts/windows-payload-contract.test.mjs` — **11/11 ناجحة**؛ هذا فحص ثابت وليس تشغيلًا على Windows.
- `npm run test:integration:pg` — اجتازت فحوص PGlite المتاحة **13/13**، بما فيها تطبيق 78 migration. هذا ليس اختبار PostgreSQL server حقيقيًا ولا يحل محل اختبار النسخ الجديد.
- اختبار النسخ `master-data-backup.postgres.spec.ts` — **3 حالات متخطاة** لأن `KAYAN_MASTER_DATA_BACKUP_PG=1` و`DATABASE_URL` غير متاحين محليًا؛ لم تُثبت دورة النسخ/الاستعادة الفعلية بعد.
- `git diff --check` — نجح.
- Flutter/Dart غير مثبتين في بيئة التنفيذ؛ لم يمكن تشغيل التحليل أو تنسيق Dart أو اختبارات الواجهة. لم يُختبر Windows فعليًا.
