**لا يزال التحويل غير آمن للتسليم:** إنشاء الفاتورة وتحديث الأمر غير ذريين، ولا توجد بعد idempotency أو حماية تزامن أو تسوية آمنة لتعديل/عكس الفاتورة المرتبطة، والتحقق من الوحدة عند تعديل مسودة لاحقًا لم يكتمل. يجب عدم اعتبار هذا التقدم حلًا للخطر المالي أو دليل إصدار.
