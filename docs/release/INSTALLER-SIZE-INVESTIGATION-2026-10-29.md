## الضغط وقيود الفحص

`installer.iss` في الشجرتين يحدد `Compression=lzma2/max` و`SolidCompression=yes`. يحمّل بناء كل منهما Node وPostgreSQL وVC runtime وقت البناء، ثم يقصد تضمين runtimes؛ هذا لا يثبت عدم حاجة التثبيت أو التشغيل إلى الشبكة.

فحص البايتات للـEXE القديم وجد معرّف `Inno Setup Setup Data (6.7.0)`، لكنه ليس فحص بنية كاملًا. `innoextract 1.9` من Ubuntu فشل بتحديد إصدار setup data؛ لذلك لم تنتج قائمة محتويات Inno القديمة أو تتأكد سلامتها به. `7z` على Windows فشل في قراءة ملف تشخيصي سابق وفي مثبت اصطناعي. لم تُشغّل أداة غير موثوقة أو يُرفع أي مثبت جديد.

**ما يلزم قبل الحكم النهائي:** الحصول على EXE الجديد نفسه ومطابقة SHA، واستخدام محلل موثوق يدعم Inno 6.7 لاستخراج جرد آمن للملفين مع الأحجام والتحقق من runtimes وDLL والترخيص، ثم تثبيت وتشغيل EXE الجديد دون إنترنت في Windows معزول واختبار backend وPostgreSQL والواجهة والترقية والاسترداد. حتى ذلك الحين اكتمال المنتج والوظائف غير مثبت.
