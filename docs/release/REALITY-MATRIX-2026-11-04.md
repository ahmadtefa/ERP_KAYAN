## الشروط الإضافية

التحويل الجزئي والأوامر مختبرة على PG لمسارات محددة، لا لكل دورات UI. backup/restore لا يثبت استعادة DB والملفات والترخيص ذريًا أو التعافي بعد crash والتزامن وTLS؛ maintenance محلي للعملية. الترخيص يرفض الحالات غير الآمنة في الاختبارات غير الموقّعة، لكن keyring الجديد واستعادة أحدث ترخيص صالح وتوقيع المنتج الفعلي لم تثبت. بيانات الشركة وصلاحيات جميع API تحتاج تدقيقًا شاملاً. المثبت الحالي لم يُبن أو يُختبر على Windows 10/11 لهذا الرأس؛ لا SHA أو رابط Setup معتمد. لا تُشغل workflows القديمة المولدة للمفاتيح أو الموقعة، ولا تغيَّر المفاتيح/Secrets أو migrations مطبقة. لا إجراء على Drive أو بيانات حقيقية.
