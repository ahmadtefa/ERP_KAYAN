## شروط إضافية لا تسقط بعد إغلاق الجدول

- تحويل/تعديل/إلغاء أوامر البيع والشراء وفواتيرها transaction/idempotency/locks/audit وتاريخ وحدة وسعر وخصم وضريبة، UI وPG، بما فيها الحدود الحالية لتعديل أمر محول جزئيًا.
- Super Admin لبيانات الشركة والشعار في كل API وaudit بنفس transaction؛ ألوان الأقسام؛ حسابات مدين/دائن وطباعة/PDF/Excel؛ عروض أسعار PDF عربية محلية متعددة الصفحات.
- النسخ والاستعادة الكاملة وTLS وcrash/concurrency/maintenance؛ ترخيص dual keyring وتحقق أصلي واستعادة أحدث صالح وربط الجهاز والإلغاء؛ حجب REVOKED/الحالة غير المعروفة وتحديثات مشروطة اجتازت اختبارات بلا توقيع وPrisma/PG في `29a7ebe`، لكن الاستعادة وkeyring والإلغاء بعد rollback والتزامن الشامل لم تثبت؛ دون تغيير المفاتيح أو Secrets حاليًا ودون مفاتيح خاصة أو توقيع خارج VM المعتمدة.
- جرد Drive read-only وحفظ أعماله دون حذف أو استبدال؛ مراجعة الاختلافات الانتقائية قبل نقلها. بوابة الإصدار تبقى فاشلة صراحة إلى أن تتوفر أدلة موثقة وتكامل تحقق معتمد.
- بناء Setup جديد من SHA محدد واختبار Windows 10 ثم 11 النظيفين offline وتشغيل/مهاجرة/ترخيص وrestart/upgrade/repair/uninstall-reinstall/restore دون فقد بيانات. لا إعلان جاهزية أو تسليم حتى إغلاق جميع الشروط وإذن النشر المنفصل.
