## القيد — يُقرأ قبل أي شيء

**صيغة JSON الرسمية هي صيغة بيانات رئيسية، وليست صيغة قاعدة بيانات كاملة.**

البرنامج يقبل ثلاثة أنواع فقط: `items` و`customers` و`suppliers`. هذه حقيقة مثبتة في
الكود نفسه (`MASTER_DATA_KINDS`) وليست اجتهادًا:

```ts
export const MASTER_DATA_KINDS = ['items', 'customers', 'suppliers'] as const;
```

لذلك **لا يمكن** تسليم ملف JSON يستعيد الفواتير والأرصدة والمستخدمين والصلاحيات
والموافقات. هذه البيانات موجودة في قاعدة البيانات، لكن مسار JSON لا ينقلها أصلًا —
لا لأن الملف ناقص، بل لأن المسار لا يعرفها. أي ملف يُبنى لهذا الغرض لن تقبله شاشة
الاسترجاع.

| ما تحمله الحزمة | ما لا تحمله |
| --- | --- |
| الأصناف: الأسماء والوحدات والباركودات والأسعار والضريبة والحد الأدنى | المستخدمون وكلمات المرور |
| أعلام الدفعات وتواريخ الصلاحية وFEFO لكل صنف | الأدوار والصلاحيات |
| العملاء: الأسماء والهواتف والضرائب وحد الائتمان وشروط السداد | فواتير البيع والشراء |
| الموردون وشروط السداد | القيود اليومية والأرصدة |
| — | حركات المخزون والدفعات والتحويلات وموافقاتها |
| — | سندات القبض والصرف |
| — | الفروع والمخازن ومراكز التكلفة |

**الفرق العملي:** من يحتاج نسخة كاملة (فواتير + أرصدة + مستخدمين + موافقات) يحتاج
ملف `.dump`، وهو الملف الذي سُلّم في المرحلة السابقة ويعمل. مسار JSON يُستخدم
لنقل البيانات الرئيسية بين التركيبات.

## قيد ثانٍ: معرّف الشركة

كل أرشيف يحمل `companyId`. البرنامج يرفض ملفًا من شركة أخرى:

```
400 — This backup belongs to a different company. Nothing was changed.
```

**هذا سلوك مقصود** يمنع خلط بيانات شركتين. قبل الاستعادة على تثبيت جديد، بدّل قيمة
`companyId` في الملف إلى معرّف شركة التثبيت الهدف. التبديل آمن: لا بصمة تشفيرية داخل
الملف، والصمتة تُحسب من محتوى القاعدة الهدف لحظة المعاينة.

لمعرفة معرّف الشركة الهدف: `GET /company` أو من الجدول `companies`.

## خطوات الاستعادة

```bash
# 1) معرّف الشركة الهدف
curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:3014/api/v1/company | jq -r .id

# 2) لكل نوع: معاينة ثم استعادة
curl -X POST .../master-data-backups/items/preview  -d '{"backup": <archive>}'
curl -X POST .../master-data-backups/items/restore  -d '{"backup": <archive>, "previewFingerprint": "<من المعاينة>"}'
```

أو من الشاشة: الإعدادات ← النسخ الاحتياطي للبيانات الرئيسية ← استيراد.
