# التصميمات الجاية من Stitch

حطّ هنا أي ملف تصدّرته من Google Stitch:

- تصدير **Flutter**: ملفات `.dart` أو ملف `.zip`.
- تصدير **HTML/CSS**: ملف `.html` وملف `.css` أو ملف `.zip`.
- صور الشاشات اللي عجبتك: `.png`.
- أي ملف قواعد تصميم جديد: `DESIGN.md`.

وبعدين قول «نزّلت التصميم»، وأنا أركّبه في البرنامج وأختبره وأرفعه.
