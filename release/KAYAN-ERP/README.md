# KAYAN ERP — مسودة تنظيم التسليم، غير صالحة للتوزيع

**لا يوجد مثبت أو مولّد مفاتيح أو أداة إصلاح تنفيذية معتمدة هنا. لا تُسلّم هذه المسودة لعميل.** النسخ والاستعادة الكاملة محجوبتان، وفحوص Windows والترخيص والتعافي المطلوبة لم تكتمل. لا توجد ملفات تنفيذية ولا أحجام أو بصمات SHA256 لملفات غير موجودة. ما يلي تنظيم للمستندات فقط وليس إصدارًا تجاريًا.

- `Documentation/`: إرشادات عربية مؤقتة وحدودها.
- `Test-Reports/STATUS.md`: تقرير الحالة والأدلة والموانع؛ التفاصيل في `docs/release/`.
- `Release-Notes/STATUS.md`: التغييرات المحلية وعدم جاهزية التسليم.
- المجلدات المطلوبة `Installer/`, `License-Generator/`, `Repair-Tool/`, `Checksums/` **لم تُنشأ كحاويات لملفات وهمية**. لا تضاف إلا عند وجود منتجات مفحوصة ومعتمدة؛ يجب مطابقة SHA256 والحجم والإصدار وتاريخ البناء للملف الحقيقي ونتائج نفس HEAD.

الاسم المستهدف بعد قبول الإصدار فقط: `KAYAN-ERP-Setup.exe`، و`KAYAN-Key-Generator.exe`. رقم `0.2.0+1` في `pubspec.yaml` هو رقم المصدر لا رقم إصدار مُعتمد. متطلب Windows 10 ثم 11 x64 هدف غير مثبت؛ لم يثبت التشغيل offline أو خلو البيئة من اعتماد خارجي. لا رابط تنزيل ولا نشر أو نسخ إلى Drive.
