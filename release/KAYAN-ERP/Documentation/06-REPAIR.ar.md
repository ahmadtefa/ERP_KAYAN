# التشخيص والإصلاح — مسودة

مصدر أداة الإصلاح موجود، لكن لا توجد أداة تنفيذية معتمدة ولا دليل اختبارها الفعلي على Windows 10 أو 11. لا تشغّل أدوات قديمة أو تعِد تثبيت البرنامج على جهاز عميل بناءً على هذا المستند.

عند مشكلة تشغيل اجمع رسالة الخطأ ووقت وقوعها وإصدار البرنامج وحالة الخدمة والصحة والشبكة دون كلمات مرور أو ملفات إعدادات سرية أو تراخيص أو محتوى قاعدة البيانات، واحفظ السجلات مقيدة الوصول بعد تنقيحها. لا تحذف ProgramData ولا ملفات الترخيص ولا قواعد البيانات.

معايير قبول الإصلاح لاحقًا: فحص الملفات والاعتماديات والخدمة وجاهزية PostgreSQL والخادم والهجرات والمنافذ والجدار الناري بالتسلسل، وتسجيل النتيجة وسبب الفشل، وفشل مغلق عند تعذر التحقق؛ ثم اختبار تكرار الإصلاح وفشل كل مرحلة دون فقد البيانات أو تغيير الترخيص أو الشبكة غير المقصود. لا يثبت وجود `repair-runtime.ps1` هذه المعايير.
