# النسخ والاستعادة — غير مكتملتين

**لا Full Backup ولا Full Restore معتمدين.** يقدم النظام أرشيف PostgreSQL لقاعدة البيانات فقط؛ لا يضم جميع الملفات الخارجية وحالة الترخيص والإعدادات المترابطة. فحص الأرشيف ونجاح تنزيله ليسا اختبار استعادة كاملة. واجهة HTTP للاستعادة الكاملة محجوبة عمدًا. احتفظ بالنسخ القديمة ولا تحذفها بناءً على هذا الأرشيف الجزئي.

نسخة JSON خاصة بالشركة مسار منفصل؛ الاستيراد قد يستبدل بيانات الشركة ولا يستعيد تركيب الجهاز أو الترخيص، وليس Full Restore. لا تستخدمه على بيانات إنتاج اعتمادًا على هذا المستند. عند تلف أو فقد البيانات، أوقف الإجراءات غير الضرورية، واحفظ الأرشيفات والبيانات وملفات الترخيص مع تقييد وصولها، واتصل بالدعم؛ لا تشغّل أوامر استعادة يدوية مدمرة.

قبل قبول الحل يجب إثبات تطابق ومصداقية DB والملفات والترخيص، سجل مراحل دائم وقفل ومنع التزامن وrollback، وتعافٍ متكرر بعد فصل الكهرباء أو إعادة التشغيل. جدول الحالات العشرين في `docs/release/BACKUP-RESTORE-LICENCE-2026-11-05.md` يبين ما قيس وما لم يُقَس.
