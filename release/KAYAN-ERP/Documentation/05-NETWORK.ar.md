# الشبكة المحلية — مرشح عنوان وليس إثبات اتصال

يعرض `/api/v1/health/network` عناوين IPv4 الخاصة المرشحة عند الربط على جميع الواجهات. بعد الإصلاح المحلي لا تُعرض الواجهات العامة كعناوين LAN؛ 169.254 عنوان رابط محلي وقد لا يكون مناسبًا للشبكة المقصودة. قد تكون الشبكة متاحة رغم عدم ظهور عنوان مدعوم في حالات كـIPv6؛ يعرض الفحص ما يعرفه الخادم، لا جميع طرق الاتصال. لا يثبت ظهور العنوان أن جهازًا آخر يستطيع الوصول أو أن الجدار الناري مضبوط.

للاختبار لاحقًا في VM وشبكة خاصة معتمدة: تحقق من نوع شبكة Windows، وعنوان الخادم والربط والمنفذ الفعلي (`3000` افتراضيًا إن كان مضبوطًا)، ثم اجعل مسؤول النظام يتحقق من قاعدة TCP واردة محددة بالنطاق والأجهزة المصرح بها وعلى Private فقط. لا تفتح قاعدة Public ولا منفذ PostgreSQL `5432`. من جهاز آخر مصرح به اختبر المنفذ ثم `/api/v1/health` والتطبيق؛ سجل ظروف الفحص ونتيجته دون بيانات اعتماد. لم يُنفذ هذا الاختبار هنا.

عنوان API المباشر `http` لا يعني وجود TLS أو reverse proxy. لا ترسل كلمات مرور أو بيانات حساسة عبر شبكة غير موثوقة؛ يلزم TLS بهوية شهادة معتمدة إن كان الاتصال معرضًا. لا تعتبر اكتشاف العنوان العام `/health/public-ip` تصريحًا بالتعريض أو إثباتًا لاتصال الإنترنت.
