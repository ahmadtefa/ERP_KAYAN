# الاستخدام — مسودة لا تعني قبول المنتج

استخدم التطبيق فقط في بيئة اختبار معزولة إلى حين اعتماد الإصدار. يعرض دليل المستخدم التفصيلي `docs/catalog/USER-GUIDE.ar.md` الوظائف كما روجعت في المصدر؛ ما زالت بعض الشاشات والسيناريوهات بحاجة إلى اختبار واجهة متصلة وWindows فعلي. لا تشارك حسابات المستخدمين أو كلمات المرور.

- اختر الشركة والفرع والفترة وفق صلاحيتك، وراجع المدخلات قبل حفظ أي مستند.
- راجع الحسابات والمخزون والضريبة ومركز التكلفة قبل الترحيل؛ إن تعذر التأكد من نتيجة الطلب بعد انقطاع الاتصال فلا تكرره عشوائيًا: راجع حالة المستند مع المسؤول أولًا.
- إلغاء التعديلات أو الرجوع قد يتطلب تأكيدًا؛ لا تفترض حفظ المسودة دون التحقق.
- راجع رصيد المخزن والقيود والتقارير بعد العملية. الصلاحيات قد تخفي إجراءات أو بيانات.
- النسخة JSON للشركة ليست نسخة كاملة، واستعادتها قد تستبدل بيانات. الاستعادة الكاملة محجوبة؛ راجع دليل النسخ ولا تستخدم مسارات قديمة.
