# التثبيت والترقية والإزالة — مسودة غير معتمدة

لا يتوفر `KAYAN-ERP-Setup.exe` معتمد على هذا الرأس. لا تستخدم مثبتًا قديمًا أو تجريبيًا مع بيانات عميل، ولا تعتمد build لـWindows باعتباره مثبتًا أو إثباتًا للعمل دون إنترنت.

## قبل الإطلاق المطلوب

على Windows 10 x64 جديد ومعزول أولًا ثم Windows 11، يلزم التحقق من محتويات الحزمة وSHA256، واختبار التثبيت دون إنترنت وبلا Node أو PostgreSQL أو Docker خارجيين، وتهيئة قاعدة البيانات والهجرات والخدمة والاختصارات، ثم فتح البرنامج والتحقق من `/api/v1/health` وتسجيل الدخول والعمليات المصرح بها. يجب تكرار التشغيل والتثبيت واختبار منافذ النظام وعدم فتح PostgreSQL للشبكة. هذه قائمة قبول، **وليست نتائج منفذة**.

## الترقية والإزالة

اختبر ترقية تثبيت قديم فعليًا في VM معزولة، مع حفظ البيانات والإعدادات والترخيص واختبار rollback بعد الفشل. لا تعِد التثبيت كحل افتراضي، ولا تفترض أن الإزالة آمنة لمجرد قراءة السكربتات. الكود الحالي يقصد إبقاء قاعدة البيانات في ProgramData عند إزالة تسجيل الخدمة، لكن سلوك إزالة المثبت وترخيصه وملفاته لم يُثبت عمليًا. الحذف الاختياري لبيانات العميل يحتاج تحذيرًا وموافقة منفصلة واختبارًا؛ لا تحذف أي بيانات الآن. لا توجد استعادة كاملة معتمدة يمكن الاتكال عليها قبل ذلك.
